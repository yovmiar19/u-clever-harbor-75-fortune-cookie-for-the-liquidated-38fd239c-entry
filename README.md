A make.fun entry: one fortune cookie message for a crypto trader who just
got liquidated. The line reads like a real fortune and lands the joke on
the loss — a wise man bought the dip, and the trader *became* the dip.

- Competition: [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c)

## Entry

> A wise man once bought the dip. You became the dip.

## How it works

`main.ts` writes the fortune, exactly as written, to `/output/entry.txt`
(UTF-8, 1–160 characters, at most 20 words). It checks the gate first and
refuses to write anything that would fail it.

Run it with Node 22+:

```sh
node main.ts
```
